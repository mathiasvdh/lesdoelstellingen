# De Academie - Ontwerpdocument

## Bordspel gebaseerd op Wingspan-mechanieken, getransformeerd naar de wereld van de filosofie

---

## 1. Het Concept

Spelers bouwen een **Academie** op door invloedrijke denkers te verzamelen, ideeen te synthetiseren en een oeuvre aan boeken te publiceren. In plaats van vogels in biotopen verzamelt de speler **Filosofen** in drie fundamentele vaardigheden: **Lezen**, **Schrijven** en **Spreken**. Het spel is een engine-builder waarbij abstracte ideeen worden omgezet in intellectuele nalatenschap.

### Spelinformatie

| Eigenschap | Waarde |
|---|---|
| Aantal spelers | 1-5 |
| Speelduur | 40-70 minuten |
| Leeftijd | 14+ |
| Taal | Nederlands |
| Rondes | 4 rondes (afnemend aantal beurten: 8/7/6/5) |

## 2. De Kernmechanieken (Vertaaltabel)

| Wingspan (origineel) | De Academie (nieuw) | Functie |
|---|---|---|
| Voedsel | **Ideeen** (dobbelstenen) | Grondstoffen om filosofen te "spelen" |
| Eieren | **Boeken** | Fiches op kaarten voor punten en om kolommen vrij te spelen |
| Biotopen (Rijen) | **Vaardigheden** | De actieruimtes op het spelersbord |
| Vogels | **Filosofen** | De kaarten met unieke krachten |
| Voederhuisje | **De Bibliotheek** | De bron van de dobbelstenen met ideeen |
| Kaarten trekken | **Dialoog** | Het ontdekken van nieuwe denkers |

---

## 3. De Grondstoffen: 5 Idee-Symbolen

Er wordt gewerkt met vijf symbolen die het brede spectrum van het denken beslaan:

| Symbool | Naam | Domein | Kleur |
|---|---|---|---|
| Weegschaal | Ethiek | Recht, Politiek, Moraalfilosofie | **Goud** |
| Oog | Waarneming | Wetenschap, Epistemologie, Kennisleer | **Blauw** |
| Spiegel | Identiteit | Antropologie, Existentialisme, Mensbeeld | **Paars** |
| Passer | Logica | Structuur, Taalfilosofie, Wiskunde | **Groen** |
| Sfeer | Metafysica | Ontologie, het Universele, Kosmologie | **Wit** |

### De Bibliotheek (Dobbelsteen-toren)

- Bevat 5 aangepaste dobbelstenen
- Elke dobbelsteen toont de 5 symbolen + 1 "Wilde Idee" (joker) zijde
- Werkt identiek aan het voederhuisje in Wingspan

---

## 4. Het Spelersbord: De Academie

Het bord bestaat uit drie rijen die sterker worden naarmate er meer filosofen liggen:

### Rij 1: LEZEN (Kennis vergaren)

> *"De ongelezen wereld is een onontgonnen wereld."*

- **Actie:** Pak Idee-fiches uit de Bibliotheek
- **Sterkte per kolom:** 1 -> 2 -> 2 -> 2+hergooi -> 3 -> 3+hergooi
- **Typische filosofen:** Analytische denkers, epistemologen, wetenschapsfilosofen
- **Voorbeelden:** Aristoteles, Descartes, Hume, Popper

### Rij 2: SCHRIJVEN (Publiceren)

> *"Een filosoof zonder oeuvre is als een boom zonder wortels."*

- **Actie:** Leg Boeken op je kaarten
- **Sterkte per kolom:** 1 boek -> 1 boek -> 2 boeken -> 2 boeken -> 3 boeken -> 3 boeken
- **Typische filosofen:** Systeemdenkers met een groot oeuvre
- **Voorbeelden:** Kant, Hegel, Marx, De Beauvoir

### Rij 3: SPREKEN (Dialoog voeren)

> *"In de dialoog wordt de waarheid geboren."*

- **Actie:** Trek nieuwe filosofenkaarten
- **Sterkte per kolom:** 1 kaart -> 1+open -> 2 -> 2+open -> 3 -> 3+open
- **Typische filosofen:** Sociale en politieke denkers, retorici
- **Voorbeelden:** Socrates, Cicero, Arendt, Habermas

## 5. De Filosofenkaarten

### 5.1 Kaartstructuur

```
+------------------------------------------+
|  [Kosten: Symbolen]        [VP: getal]   |
|                                          |
|         PORTRET / ILLUSTRATIE            |
|                                          |
|  NAAM FILOSOOF                           |
|  Geboorte - Overlijden                   |
|  Stroming / Traditie                     |
|                                          |
|  Vaardigheden: [L] [S] [Sp]             |
|  Boek-capaciteit: [X boeken]             |
|                                          |
|  +------------------------------------+ |
|  | KRACHT (kleur-gecodeerd)            | |
|  | Beschrijving van de actie           | |
|  +------------------------------------+ |
|                                          |
|  Citaat in cursief                       |
+------------------------------------------+
```

### 5.2 Vaardigheidspictogrammen

- **[L]** = Lezen (boek-icoon) - Kan in rij 1 geplaatst worden
- **[S]** = Schrijven (pen-icoon) - Kan in rij 2 geplaatst worden
- **[Sp]** = Spreken (podium-icoon) - Kan in rij 3 geplaatst worden
- De meeste filosofen hebben alle drie de iconen
- **Specialisten** hebben slechts 1 of 2 iconen (bijv. Socrates: enkel Spreken)

### 5.3 Krachttypes (Kleurcodering)

| Kleur | Type | Wingspan-equivalent | Activatie |
|---|---|---|---|
| **Bruin** | Tijdens Onderzoek | "When activated" | Elke keer dat de rij wordt geactiveerd |
| **Roze** | Tijdgeest | "Once between turns" | Eenmaal tussen beurten (ook bij medespelers) |
| **Wit** | Bij Aanstelling | "When played" | Eenmalig bij het spelen van de kaart |

### 5.4 Verdeling van Krachten (170 kaarten totaal)

| Categorie | Percentage | Aantal | Beschrijving |
|---|---|---|---|
| Extra Ideeen | 35% | ~60 | Genereert extra grondstoffen |
| Extra Kaarten | 20% | ~34 | Trekt extra filosofenkaarten |
| Referenties (tuck) | 25% | ~42 | Ondersteken van kaarten voor VP |
| Boeken + Tijdgeest | 20% | ~34 | Extra boeken of roze krachten |

## 6. Spelverloop

### 6.1 Opzet

1. Elke speler ontvangt een spelersbord (De Academie)
2. Elke speler trekt 5 filosofenkaarten en houdt er een aantal
3. Elke speler ontvangt 5 Idee-fiches en houdt er een aantal (totaal kaarten + ideeen = 5)
4. Elke speler trekt 2 "Levenswerk"-kaarten (bonus-doelen) en houdt er 1
5. Onthul de eerste "Paradigmaverschuiving"-tegel (ronde-doel)

### 6.2 Rondestructuur

| Ronde | Naam | Beurten per speler |
|---|---|---|
| 1 | De Oudheid | 8 |
| 2 | De Middeleeuwen | 7 |
| 3 | De Verlichting | 6 |
| 4 | De Moderne Tijd | 5 |

### 6.3 Acties per Beurt

Een speler kiest **een** van vier acties:

1. **Een Filosoof Aanstellen** - Betaal de Idee-kosten en plaats een filosoof in een vaardigheidrij
2. **Lezen** - Activeer de Lezen-rij om Ideeen te verzamelen
3. **Schrijven** - Activeer de Schrijven-rij om Boeken te publiceren
4. **Spreken** - Activeer de Spreken-rij om nieuwe kaarten te trekken via Dialoog

Bij acties 2-4 worden alle "Tijdens Onderzoek"-krachten (bruin) in die rij van rechts naar links geactiveerd.

## 7. Puntentelling

### 7.1 Puntenbronnen

| Bron | Beschrijving |
|---|---|
| Filosofen (VP) | Vaste punten op elke kaart |
| Boeken | 1 punt per boek op het bord |
| Referenties | 1 punt per ondergestoken kaart |
| Paradigmaverschuivingen | Punten uit ronde-doelen (1e/2e/3e plaats) |
| Levenswerk | Bonuspunten uit persoonlijk einddoel |
| Opgeslagen Ideeen | 1 punt per overgebleven Idee-fiche |

### 7.2 Balansprincipes

| Kosten (Ideeen) | Verwachte VP-range | Opmerking |
|---|---|---|
| 0 | 1-3 | Goedkope "starter"-denkers |
| 1 | 3-5 | Vroege engine-builders |
| 2 | 5-7 | Solide middenspel |
| 3 | 7-9 | Krachtige denkers |
| 4+ | 9-12 | Dure maar zeer invloedrijk |

## 11. Uitbreidingsmogelijkheden

Het systeem is modulair gebouwd:

- **Oosterse Filosofie**: Confucius, Laozi, Boeddha, Avicenna, Nagarjuna
- **Islamitische Filosofie**: Al-Kindi, Al-Farabi, Ibn Rushd, Al-Ghazali
- **Afrikaanse Filosofie**: Ubuntu, Kwame Nkrumah, Frantz Fanon
- **Politieke Filosofie**: Extra nadruk op staatstheorie en rechtvaardigheid
